# Toktar Fight Club — сайт (демо)

Еркебұлан Тоқтардың жекпе-жек клубына арналған 3D анимациялы сайт (қазақша / орысша).

## Не бар
- 3D қасқыр эмблемасы (Three.js): тышқанға қарай бұрылады, айналасында айналатын жазу мен ұшқындар бар
- Интерактивті 3D боксёр қапшығы: соққы күші, соққы саны, рекорд, «НОКАУТ!» эффектісі
- Тегіс айналдыру (Lenis), GSAP анимациялары, бағыттар бөлімі көлденең айналады (компьютерде)
- Кесте, абонемент, FAQ, «Ерте жазылу» формасы (Netlify Forms), байланыс

## Деректерді толтыру
Барлық өзгеретін ақпарат `js/config.js` файлында: ашылу күні (кері санақ), телефон, WhatsApp, мекенжай, карта, апталық кесте.
Мәтіндер `js/i18n.js` файлында екі тілде (`kk`, `ru`). Бұл файлдарды өзгерткен соң қайта жинау (build) керек емес.

Демо нұсқа: бағалар, кесте және FAQ мәтіндері үлгі ретінде жазылған, оларды клубпен келісіп нақтылау керек.

## Суреттер
- `img/founder.jpg` — Еркебұланның фотосы (4:5). Файл болса, автоматты түрде шығады.
- `img/logo.svg` — уақытша логотип. Клубтың түпнұсқа логотипімен ауыстырыңыз.

## 3D/анимация кодын өзгерту
Код `src/` папкасында. Өзгерткен соң:

```
npm install
npm run build   # js/bundle.js файлын қайта жинайды
```

## Netlify-ға шығару
Осы папканы Netlify-ға жүктеңіз (publish = "."). Өтінімдер Netlify → Forms → `early-signup` бөлімінде көрінеді.
