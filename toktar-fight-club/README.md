# Toktar Fight Club — сайт

Еркебұлан Тоқтардың жекпе-жек клубына арналған статикалық сайт (қазақша / орысша).

## Деректерді толтыру
Барлық өзгеретін ақпарат `js/config.js` файлында: ашылу күні (кері санақ), телефон, WhatsApp, мекенжай, карта, бургер брендінің атауы мен сілтемелері.
Мәні бос болса, ол элемент сайтта көрсетілмейді.

## Суреттер
- `img/founder.jpg` — Еркебұланның фотосы (4:5). Файл болса, автоматты түрде шығады.
- `img/logo.svg` — уақытша логотип. Клубтың түпнұсқа логотипімен ауыстырыңыз.

## Мәтіндер
`js/i18n.js` — барлық мәтін екі тілде (`kk`, `ru`).

## Netlify-ға шығару
Осы папканы Netlify-ға жүктеңіз (publish = "."). "Ерте жазылу" формасы Netlify Forms арқылы жұмыс істейді: өтінімдер Netlify → Forms → `early-signup` бөлімінде көрінеді.
