# FluentPath — ағылшын тілін қазақша үйрен

Қазақ тілді оқушыларға арналған тегін веб-қосымша: A1-ден B2-ге (IELTS) дейінгі сабақ жолы, ақылды қайталау, грамматика, listening, speaking, writing. Сервер керек емес — бәрі браузерде жұмыс істейді, интернетсіз де ашылады.

## Не бар

- **Сабақ жолы (Duolingo стилі)** — 4 бөлім (A1 Негіздер → B2 IELTS Academic), 40-тан астам тарау, 229 түйін. Әр тарау: сөз сабақтары + грамматика + тарау қорытындысы.
- **13 жаттығу түрі** — жаңа сөзбен танысу, аударма таңдау, тыңдап таңдау, тыңдап жазу, ағылшынша жазу, бос орынды толтыру, тыңдап сөйлем құрастыру, қазақшадан сөйлем құрастыру, жұп табу, грамматика тесті, ереже карточкасы, **дауыстап айту** (микрофон сөзді/сөйлемді таниды; «Қазір сөйлей алмаймын» батырмасы бар).
- **Қате болса қайта сұралады**, кішкене опечатка кешіріледі, комбо 🔥, жұлдыздар ★★★, дыбыс эффектілері.
- **Секіру тесті** — деңгейің жоғары болса, бөлімді тест арқылы ашасың.
- **Ақылды қайталау (spaced repetition)** — Leitner жүйесі: 1 → 2 → 4 → 7 → 15 → 30 → 60 күн. Есте сақтау күші мен алдағы 7 күннің болжамы.
- **877 сөз** (A1 132 · A2 129 · B1 81 · B2 535) қазақша аудармасы мен мысалымен.
- **Табиғи дауыстар** — сөздер, мысалдар, тыңдау мәтіндері мен әңгімелер нейрон дауыспен алдын ала жазылған (Kokoro, тегін Apache-2.0 модель): әр телефонда бірдей, әдемі дыбыс. Әңгімеде қыз бен әйел — әйел дауысымен, ұл мен ер адам — ер дауысымен сөйлейді; тыңдау тректері әйел/ер дауысымен кезектеседі. Жазылмаған мәтінді (AI чат жауабы) құрылғының ең жақсы ағылшын дауысы оқиды, кейіпкердің жынысы сақталады.
- **18 грамматика сабағы** қазақша түсіндірмемен және жаттығулармен.
- **IELTS құралдары** — 15 listening трек, speaking cue card + таймер, writing тапсырмалары (автосақтау), фразалар, 15 reading мәтін (A1–B2), деңгей тесті.
- **Диалог-оқиғалар** — 8 қысқа оқиға (A1–B2): репликалар әр дауыспен оқылады, басқанда қазақша аудармасы шығады, арасында түсіну сұрақтары.
- **IELTS mock test** — 4 бөлім уақытпен (Listening 10 мин, Reading 20 мин, Writing 40 мин, Speaking Part 2), соңында band болжамы; Writing/Speaking-ті AI бағалайды.
- **ҰБТ ағылшын тесті** — ҰБТ форматы: 40 сұрақ, 60 минут, 50 балл (25 бір жауапты, 5 мәтін бойынша, 10 бірнеше жауапты — 2 балдан), соңында қате талдауы.
- **Мотивация** — күнделікті XP мақсаты (10/20/30/50), streak, апталық график, 10 жетістік, **күнделікті 3 тапсырма** (+10 XP), **апталық челлендж** (+50 XP), **streak қорғанысы** 🧊 (әр 7 күн сайын біреу, ең көбі 2; бір күн өткізіп алсаң streak үзілмейді).
- **Аккаунт және бұлт** (Supabase қосылса) — email кодымен кіру (құпиясөзсіз), прогресс барлық құрылғыда синхрондалады, **апталық лига**, **сынып / мұғалім режимі** (сынып коды немесе сілтеме, тапсырма беру, оқушылардың XP/streak/сабақ/тапсырма кестесі), **push еске салғыш** (кешкі 19:00, тек сол күні сабақ жасамағандарға).
- **AI серік (Gemini)** — 6 жағдаят бойынша ағылшынша сөйлесу (кафе, әуежай, дүкен, жұмыс сұхбаты, IELTS Part 1, еркін әңгіме): қатені қазақша түзетеді, жауапты аударады, дауыспен айтуға болады.
- **AI тексеру** — Writing эссесіне IELTS band (4 критерий), қателер тізімі, жақсартылған нұсқа; Speaking жауабын микрофонмен жазып, AI бағалайды.
- **PWA** — телефонға қосымша ретінде орнатылады, offline жұмыс істейді.
- **Интерфейс тілі:** қазақша · орысша, қараңғы/ашық тақырып.
- Прогресс браузерде (`localStorage`) сақталады, JSON арқылы export/import. Аккаунтпен кірсе — бұлтқа да.

## Іске қосу

Жай ғана `index.html`-ді браузерде аш. Service worker (offline) тек `http(s)://` арқылы жұмыс істейді:

```bash
cd FluentPath-deploy
python3 -m http.server 8000
# http://localhost:8000
```

Netlify-ге: осы папканы деплой ет (`netlify.toml` дайын).

## AI-ды қосу (тегін Gemini)

1. [aistudio.google.com](https://aistudio.google.com) → **Get API key** → тегін кілт ал.
2. Netlify → сайтың → **Site configuration → Environment variables** → `GEMINI_API_KEY` = кілтің.
3. Қаласаң `GEMINI_MODEL` қос (әдепкі: `gemini-flash-latest` — ең жаңа Flash моделі).
4. Сайтты қайта deploy ет. Netlify сайты GitHub-қа қосылған болуы керек (drag-and-drop deploy функцияларды іске қоспайды), Base directory — `FluentPath-deploy`.

Кілт тек серверде (`netlify/functions/ai.js`) қолданылады, браузерге берілмейді. Тегін тарифте минутына/күніне сұрау саны шектеулі — лимит біткенде сайт «1 минуттан кейін қайта көр» деп жазады.

Жергілікті тексеру үшін: **Прогресс → Баптаулар → AI (Gemini)** ішіне өз кілтіңді енгізуге болады — ол тек сол құрылғыда сақталады.

## Аккаунт, лига, мұғалім режимі және еске салғыш (тегін Supabase)

Бұл бөлімсіз де сайт толық жұмыс істейді — аккаунт батырмалары жай ғана көрінбейді. Қосу үшін (~10 минут):

1. [supabase.com](https://supabase.com) → тегін тіркел → **New project** (аймақ: Frankfurt немесе ең жақыны).
2. **SQL Editor → New query** → `supabase/schema.sql` файлының ішін толық көшіріп қой → **Run**. Кестелер мен қауіпсіздік ережелері (RLS) жасалады.
3. **Authentication → URL Configuration**: *Site URL* = сайтыңның адресі (мысалы `https://fluentpath.netlify.app`), *Redirect URLs* ішіне де соны қос.
4. **Authentication → Emails → Magic Link** шаблонына кодты қос, мысалы: `<p>Кіру коды: <b>{{ .Token }}</b></p><p>немесе <a href="{{ .ConfirmationURL }}">осы сілтемені бас</a></p>`. (Кодпен кіру PWA мен телефонда ыңғайлы.)
5. **Project Settings → API** бетінен үш мәнді ал да, Netlify → **Site configuration → Environment variables** ішіне қос:
   - `SUPABASE_URL` — Project URL
   - `SUPABASE_ANON_KEY` — `anon` `public` кілт (браузерге берілетін ашық кілт, деректерді RLS қорғайды)
   - `SUPABASE_SERVICE_ROLE_KEY` — `service_role` кілт (**құпия**, тек еске салғыш функциясы қолданады; ешқашан кодқа жазба)
6. Push еске салғыш үшін VAPID кілттерін жаса: `node scripts/vapid-keys.mjs` → шыққан `VAPID_PUBLIC_KEY` және `VAPID_PRIVATE_KEY` мәндерін Netlify-ге қос, тағы `VAPID_SUBJECT` = `mailto:сенің@email.kz`. Жеке кілтті репозиторийге жазба.
7. Сайтты қайта deploy ет. Жоғарғы панельде 👤 батырмасы, «Тағы» мәзірінде Лига мен Сынып пайда болады.

Ескертпелер:

- Supabase-тің тегін email жіберуі сағатына бірнеше хатпен шектеулі. Оқушылар көп болса, **Authentication → Emails → SMTP** арқылы өз поштаңды (мысалы Gmail, Resend, Brevo) қос.
- Еске салғыш `netlify/functions/reminders.js` күн сайын 14:00 UTC-та (Қазақстанда 19:00) іске қосылады (`netlify.toml`). Android/компьютерде браузерде жұмыс істейді; iPhone-да алдымен сайтты «Home Screen»-ге қосу керек (iOS 16.4+).
- Мұғалім режимі: кез келген аккаунт «Сынып → Мұғалім» бөлімінде сынып аша алады. Оқушыға 6 таңбалы кодты немесе «Сілтемені көшіру» сілтемесін (WhatsApp-қа) жібер. Мұғалім тек өз сыныбындағы оқушылардың атын, XP, streak, сабақ санын және тапсырмаларын көреді — email көрінбейді.
- Лигадағы ат — аккаунт бетінде өзгертілетін ат; әдепкі ат «Оқушы XXXX», email ешқашан көрсетілмейді.

```
index.html            — барлық бет (view) + сабақ ойнатқышы

js/data.js            — негізгі контент: сөздер, грамматика, listening, reading…
js/course-data.js     — A1/A2 сөздер, жаңа грамматика сабақтары, жаттығулар
js/i18n.js            — интерфейс аудармалары (kk, ru)
js/srs.js             — spaced repetition алгоритмі
js/app.js             — негізгі логика, навигация, сөздік, тест, прогресс
js/voice.js           — дауыстар: жазылған клиптер + құрылғы дауысы (жынысы бойынша)
js/audio-index.js     — жазылған клиптер тізімі (скрипт жасайды)
audio/                — нейрон дауыспен жазылған MP3 клиптер
js/course.js          — сабақ жолы, сабақ ойнатқышы, қайталау беті
js/ai-prompts.js      — AI тапсырмалары: промпттар, жауап схемасы, Gemini шақыру (браузер + сервер ортақ)
js/ai.js              — AI клиенті (Netlify функциясы немесе жеке кілт)
js/ai-ui.js           — AI серік чаты және band бағасы карточкасы
js/content-extra.js   — қосымша reading мәтіндер, диалог-оқиғалар, ҰБТ көп жауапты сұрақтар
js/quests.js          — күнделікті тапсырмалар мен апталық челлендж
js/stories.js         — диалог-оқиғалар ойнатқышы
js/exams.js           — IELTS mock test және ҰБТ тесті
js/cloud.js           — Supabase: кіру, синхрондау, лига, сыныптар, push жазылым (SDK-сыз, REST)
js/cloud-ui.js        — Аккаунт, Лига, Сынып беттері
netlify/functions/ai.js — Gemini-ге серверлік прокси (GEMINI_API_KEY)
netlify/functions/config.js — браузерге ашық баптаулар (Supabase URL, anon кілт, VAPID public)
netlify/functions/reminders.js — күнделікті push еске салғыш (scheduled)
supabase/schema.sql   — дерекқор кестелері мен RLS ережелері
scripts/vapid-keys.mjs — push үшін VAPID кілттерін жасау
scripts/build-audio.mjs, scripts/tts-kokoro.py — дауыстарды жазу
sw.js                 — offline кэш
manifest.webmanifest  — PWA манифест
icons/                — қосымша иконкалары
```

## Дауыстарды қайта жазу (жаңа сөз не мәтін қосқанда)

```bash
python3 -m venv .tts && .tts/bin/pip install kokoro-onnx soundfile
curl -LO https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/kokoro-v1.0.onnx
curl -LO https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/voices-v1.0.bin
PYTHON=.tts/bin/python node scripts/build-audio.mjs
```

ffmpeg керек. Скрипт тек жетіспейтін дыбыстарды жазады (`audio/<дауыс>/<хеш>.mp3`) және `js/audio-index.js` тізімін жаңартады. Модель файлдарын (`*.onnx`, `*.bin`) репозиторийге қоспа. Дауыстарды ауыстыру — `js/voice.js` ішіндегі `VOICES`.

## Жаңа нұсқа шығарғанда

`sw.js` ішіндегі `VERSION` мен `index.html` ішіндегі `?v=` мәндерін бірге көбейт (мысалы `3` → `4`). Әйтпесе пайдаланушылардың браузері ескі файлдарды кэштен көрсете береді.

## Контент қосу

- Жаңа сөз: `js/course-data.js` ішіндегі `BASIC` тізіміне `[en, kk, example]` қос. Сөздің id-і ағылшын сөзінен жасалады (`w_good_morning`), сондықтан прогресс сақталады.
- Жаңа грамматика жаттығуы: `DRILLS` объектісіне `mcq(...)` немесе `build(kk, en)` қос.
- Сабақ жолы контенттен автоматты құрылады: деңгей → тақырып → 6 сөзден сабақ.
