# BilimPath — ҰБТ-ға дайындық

ҰБТ форматындағы жаттығу және сынақ платформасы. HTML/CSS/JS, сервер мен тіркелу керек емес, прогресс браузерде (localStorage) сақталады.

## Не бар

- **14 пән**: Қазақстан тарихы, оқу сауаттылығы, математикалық сауаттылық + 11 бейіндік пән (математика, физика, химия, биология, география, дүниежүзі тарихы, құқық негіздері, информатика, ағылшын тілі, қазақ тілі, қазақ әдебиеті)
- **735 сұрақ** + **59 есеп генераторы** (математика, физика, химия, информатика, география, мат. сауаттылық — сандары әр жолы жаңа, жауабы есептеліп шығады)
- **ҰБТ-дағы 4 тапсырма түрі**: бір жауап, контекст (мәтінмен), сәйкестендіру (2 балл), бір/бірнеше жауап (2 балл; бір қате — 1 балл)
- **Толық сынақ**: 5 пән, 120 тапсырма, 140 балл, 240 минут, 11 бейіндік комбинация, шекті балды тексеру
- **Мини-сынақ**: 60 тапсырма, 70 балл, 120 минут
- **Қателер банкі** — қате жауаптар жиналады, дұрыс шешкенде шығады
- **Прогресс**: сынақ балдарының графигі, пәндер бойынша дәлдік, әлсіз тақырыптар, ҰБТ күніне кері санақ, мақсатты балл
- Жарық/қараңғы тақырып, телефонға бейімделген

## Іске қосу

`index.html` файлын браузерде аш немесе папканы Netlify-ға жүкте (`netlify.toml` дайын).

## Сұрақ қосу

Сұрақтар `js/bank/*.js` файлдарында. Пішімі `js/bank-core.js` басында сипатталған — дұрыс жауап әрқашан бірінші жазылады, қолданба нұсқаларды өзі араластырады:

```js
UBT.add("history", "Қазақ хандығы", [
  ["s", "Қазақ хандығы қай жылы құрылды?", ["1465 жылы", "1428 жылы", "1511 жылы", "1500 жылы"], "Түсіндірме."],
]);
```

Қосқаннан кейін тексер:

```bash
node tools/validate.js
```

## Файлдар

```
index.html
css/style.css
js/bank-core.js     — пәндер, ҰБТ форматы, сұрақ жүктегіш
js/bank/*.js        — пәндер бойынша сұрақтар
js/generators.js    — есеп генераторлары
js/app.js           — қолданба логикасы
tools/validate.js   — банкті тексеру
```

## Ескерту

Сұрақтар ҰТО-ның ашық құрылымына сәйкес жасалған түпнұсқа тапсырмалар (ресми сұрақтар көшірілмеген). ҰТО форматты жыл сайын жаңартады, ресми ақпаратты [testcenter.kz](https://testcenter.kz) сайтынан тексер.
