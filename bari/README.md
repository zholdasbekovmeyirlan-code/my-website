# Бәрі — бәрі бір қосымшада

Такси, тамақ жеткізу, дүкен, дәріхана және курьер бір қосымшада. Yandex Go сияқты, бірақ басты мақсаты — халыққа пайда әкелу.

> **Прототип 0.1.** Тапсырыстар шын жіберілмейді, ақша алынбайды, жүргізушілер мен курьерлер ойдан шығарылған. Бұл қосымшаның қалай жұмыс істейтінін көрсететін, басып көруге болатын нұсқа.

## Не бар

| Бөлім | Мүмкіндіктер |
|---|---|
| **Такси** | Карта (OpenStreetMap), мекенжай іздеу, картадан нүкте таңдау, 5 тариф (Эконом, Комфорт, Балалар, Бизнес, Әлеуметтік), баға есебі, жүргізуші іздеу, машинаның картада қозғалуы, бас тарту, бағалау және шай-пұл |
| **Курьер** | Сәлемдеме жіберу: жаяу, көлікпен, жүк көлігі |
| **Тамақ** | 8 мейрамхана, санаттар, іздеу, мәзір, себет, тапсырысты тірі бақылау (қабылданды, дайындалып жатыр, курьер жолда, жеткізілді) |
| **Дүкен мен дәріхана** | Азық-түлік және дәрі-дәрмек каталогы, сол себет арқылы |
| **Тапсырыстар** | Белсенді тапсырыстар мен тарих, чек, тапсырысты қайталау |
| **Профиль** | Аты, телефон, тіл (қазақша / орысша), жарық/қараңғы көрініс, әлеуметтік мәртебе |

### Халыққа пайдасы («Бірге» бөлімі)

- **Әділ комиссия.** Жүргізуші мен курьер 90% алады. Бұл әр чекте көрсетіледі.
- **Әлеуметтік тариф.** Зейнеткерлерге, мүгедектігі бар адамдарға, көпбалалы отбасыларға такси 30% арзан.
- **Дөңгелектеп, көмектес.** Тапсырыс сомасын 500 ₸-ге дейін дөңгелектеп, айырмасын қайырымдылыққа беру.
- **Қалдықсыз тамақ.** Кешке сатылмай қалған тамақты жеңілдікпен сату (тамақ тасталмайды).
- **Жергілікті бизнеске қолдау.** Шағын кафелер мен дүкендер алғашқы 3 ай комиссиясыз жұмыс істейді.
- **Жүргізуші, курьер, серіктес болу** үшін өтінім формасы.

## Қалай ашу керек

Ешнәрсе орнатудың қажеті жоқ: `index.html` файлын браузерде ашыңыз.

Жергілікті сервер арқылы (карта мен іздеу жақсырақ жұмыс істейді):

```bash
npx serve bari
```

Телефонда ашқанда «Басты экранға қосу» батырмасы арқылы қосымша ретінде орнатуға болады.

## Netlify-ға жүктеу

1. Netlify → **Add new site → Import from Git** → осы репозиторий.
2. **Base directory:** `bari`
3. **Publish directory:** `bari` (build командасы керек емес).

## Файлдар

```
bari/
  index.html            — қосымшаның қаңқасы
  css/style.css         — дизайн (жарық және қараңғы тақырып)
  js/data.js            — орындар, тарифтер, мейрамханалар, мәзір
  js/i18n.js            — барлық мәтін: қазақша және орысша
  js/store.js           — күй (state), сақтау, баға есебі, тапсырыс статустары
  js/ui.js              — иконкалар, навигация, терезелер, хабарламалар
  js/map.js             — Leaflet картасы
  js/taxi.js            — такси және курьер
  js/shop.js            — тамақ, дүкен, дәріхана, себет, тапсырысты бақылау
  js/screens.js         — басты бет, тапсырыстар, «Бірге», профиль
  vendor/leaflet/       — карта кітапханасы (BSD-2 лицензиясы)
```

## Нақты өнімге айналдыру үшін не керек

Прототип — бірінші қадам. Шын қызмет болу үшін:

1. **Сервер (backend).** Пайдаланушылар, тапсырыстар, жүргізушілер дерекқоры. Мысалы: Node.js + PostgreSQL немесе Supabase / Firebase.
2. **Нақты уақыт.** Жүргізуші мен курьердің орнын WebSocket арқылы жіберу.
3. **Тағы екі қосымша.** Жүргізуші/курьер қосымшасы және мейрамхана/дүкен панелі.
4. **Карта мен маршрут.** Қазақстанда 2GIS кең тараған; Google Maps немесе Mapbox те бар. OpenStreetMap-тың тегін серверлері тек сынақ үшін.
5. **Төлем.** Банк эквайрингі немесе Қазақстандағы төлем жүйелерімен келісім.
6. **Кіру.** SMS арқылы телефон нөмірін растау.
7. **Әлеуметтік мәртебені тексеру.** eGov арқылы.
8. **Заң жағы.** Компания тіркеу, такси және жеткізу қызметіне қойылатын талаптар, дербес деректерді қорғау туралы заң.
9. **Мобильді қосымша.** Қазіргі веб-нұсқа (PWA) телефонда жұмыс істейді; кейін React Native немесе Flutter арқылы App Store / Google Play-ге шығаруға болады.
