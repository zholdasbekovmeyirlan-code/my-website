# Edgebook — Premium Trading Journal

Трейдерлерге арналған премиум журнал: мәмілелерді жазу, капитал қисығы, P&L күнтізбесі, терең аналитика және күнделік.
Таза HTML/CSS/JS, кітапханасыз, серверсіз. Барлық деректер тек браузерде (localStorage) сақталады.

## Ашу

```bash
cd Edgebook
python3 -m http.server 8080
# → http://localhost:8080
```

Немесе `index.html` файлын браузерде тікелей ашыңыз.

## Deploy (Netlify)

- **Netlify Drop:** `Edgebook` папкасын app.netlify.com/drop бетіне сүйреп апарыңыз.
- **Git арқылы:** Netlify-да *Base directory* = `Edgebook`, *Publish directory* = `.` (`netlify.toml` дайын).

## Не бар

**Басты бет (`index.html`)**
- Анимацияланған aurora фон, үлкен serif тақырып, скролл кезінде 3D-дан түзуленетін тірі dashboard макеті
- Bento-стильдегі мүмкіндіктер (тірі графиктермен), аналитика бөлімі, «Қалай жұмыс істейді», баға, FAQ
- Курсорға ілесетін жарық (spotlight), скролл анимациялары, KK / EN

**Қолданба (`app.html`)**

**Шолу (Dashboard)**
- Таза P&L, ұтыс үлесі (donut), Profit factor, күтілетін нәтиже, жиынтық R, орт. ұтыс/шығын, макс. құлдырау
- Интерактивті капитал қисығы (crosshair + tooltip), күндік P&L бағандары, сетап бойынша нәтиже
- Уақыт аралығы: 7D · 30D · 90D · YTD · Барлығы

**Мәмілелер**
- Іздеу, бағыт / нәтиже / сетап сүзгілері, баған бойынша сұрыптау, беттеу, CSV экспорт
- Мәміле формасы: live preview (P&L, R, тәуекел %, жоспар R:R), 2%-дан жоғары тәуекел туралы ескерту
- Эмоция, қателер, орындау сапасы (★), тегтер, жазбалар, скриншот (drag & drop / Ctrl+V, автоматты сығу)
- Мәмілені қарау, өңдеу, көшірме жасау, өшіру

**Күнтізбе** — айлық P&L жылу картасы, апталық қорытынды, күнді басқанда — сол күннің мәмілелері мен жазбалары

**Аналитика**
- Автоматты инсайттар (ең мықты/әлсіз сетап, күн, сағат, эмоция, қателер құны)
- Апта күні, сағат, R таралуы, Long vs Short, актив бойынша, қателер құны
- Сетап және эмоция кестелері (win rate, PF, орт. R, P&L), орындау сапасы vs нәтиже

**Күнделік** — нарық алдындағы жоспар, күн талдауы, сабақтар, көңіл-күй / фокус шкаласы, автосақтау

**Баптаулар** — аты, бастапқы баланс, валюта (USD, EUR, KZT, RUB, USDT, GBP), тіл, сетаптар тізімі, JSON backup / restore, CSV, демо деректер

**UI** — ⌘K / Ctrl+K командалар палитрасы, сандардың санау анимациясы, курсорға ілесетін жарық, қараңғы / жарық тақырып, Қазақша / English, мобильді нұсқа (төменгі навигация, bottom-sheet модальдар)

## Есептеу

- **P&L** = (шығу − кіру) × көлем × мультипликатор × бағыт − комиссия
- **R** = таза P&L / (|кіру − стоп| × көлем × мультипликатор)
- **Profit factor** = жалпы пайда / жалпы шығын
- **Макс. құлдырау** — капитал қисығының шыңнан түбіне дейінгі ең үлкен төмендеуі
