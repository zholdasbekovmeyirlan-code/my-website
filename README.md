# Бәрі — бәрі бір қосымшада

Такси, курьер, тамақ, дүкен мен дәріхана жеткізу бір платформада. Қазақстанға арналған, Yandex Go сияқты қызмет. Басты мақсаты — халыққа пайда әкелу.

**Нұсқа 0.2.** Тапсырыстарды нақты адамдар орындайды: клиент тапсырыс береді, жүргізуші немесе курьер оны өз қосымшасында қабылдайды, мейрамхана өз панелінде дайындайды. Бәрі нақты уақытта жаңарады.

## Төрт қосымша, бір сервер

| Мекенжай | Кімге | Не істейді |
|---|---|---|
| `/` | **Бәрі** — клиенттерге | Такси мен курьер шақыру, тамақ, дүкен мен дәріхана тапсырысы, жүргізушіні картадан бақылау, бағалау |
| `/pro` | **Бәрі Pro** — жүргізуші мен курьерге | Өтінім беру, желіге шығу, тапсырыс қабылдау, клиентке бару, табысты көру |
| `/partner` | **Бәрі Бизнес** — мейрамхана мен дүкенге | Мекемені тіркеу, мәзірді басқару, тапсырысты қабылдау немесе қайтару, «Дайын» деп белгілеу, сатылымды көру |
| `/admin` | **Әкімші** | Жүргізушілерді, курьерлерді және мекемелерді растау, әлеуметтік мәртебені тексеру, статистика |

```
 Клиент ─┐                         ┌─ Жүргізуші / курьер (Pro)
         ├── Сервер (API + SQLite) ─┤
 Әкімші ─┘   нақты уақыт (SSE)     └─ Мейрамхана (Бизнес)
```

### Тапсырыс қалай өтеді

- **Такси:** клиент шақырады → жақын маңдағы желідегі жүргізушілерге ұсыныс барады → біреуі қабылдайды → «Келдім» → «Сапарды бастау» → «Аяқтау» → клиент бағалайды.
- **Курьер:** сәлемдеме жіберу. Жаяу, көлікпен және жүк көлігімен.
- **Тамақ / дүкен:** клиент тапсырыс береді → мекеме қабылдайды → курьер алады → мекеме «Дайын» дейді → курьер апарады.

### Халыққа пайдасы

- **Әділ комиссия.** Жүргізуші мен курьер 90% алады, шай-пұлдың бәрі соларға. Бұл әр чекте көрсетіледі.
- **Әлеуметтік тариф.** Зейнеткерлерге, мүгедектігі бар адамдарға және көпбалалы отбасыларға такси 30% арзан. Мәртебені әкімші тексереді.
- **Дөңгелектеп, көмектес.** Тапсырыс сомасы 500 ₸-ге дейін дөңгелектеніп, айырмасы қайырымдылыққа барады.
- **Қалдықсыз тамақ.** Мейрамхана кешке сатылмай қалған тамақты жеңілдікпен сата алады (мәзірде «Кешкі жеңілдік»).
- **Жергілікті бизнес.** Жаңа серіктестер алғашқы кезде комиссиясыз жұмыс істейді. Комиссияны әкімші өзгертеді.

## Компьютерде іске қосу

Тек **Node.js 22.13 немесе одан жаңа** нұсқасы керек. Қосымша кітапхана орнатудың қажеті жоқ.

```bash
cd server
cp .env.example .env      # ADMIN_PHONES жолына өз нөміріңізді жазыңыз
npm start
```

Содан кейін браузерде мына беттерді ашыңыз: http://localhost:3000 (клиент), `/pro`, `/partner`, `/admin`.

**Бірнеше рөлді бір компьютерде қалай тексеруге болады.** Әр рөлді бөлек браузерде немесе инкогнито терезесінде, әр түрлі телефон нөмірімен ашыңыз. `SMS_MODE=demo` режимінде SMS жіберілмейді, кіру коды экранда көрсетіледі.

**Тест режимі.** `SIMULATE=1` болса, Pro қосымшасында «Тест: маршрутпен автоматты жүру» белгісі шығады. Сонда машина картада өзі жүреді.

**Тесттер:**

```bash
cd server && npm test
```

Тест бес рөлдің бәрін тексереді: клиент, жүргізуші, курьер, мекеме және әкімші.

## Интернетке шығару (достарыңызбен тексеру үшін)

### Render.com (ең оңай жол)

1. https://render.com сайтында GitHub арқылы тіркеліңіз.
2. **New → Blueprint** батырмасын басып, осы репозиторийді таңдаңыз. `render.yaml` файлы бәрін өзі баптайды.
3. `ADMIN_PHONES` өрісіне өз нөміріңізді жазыңыз, мысалы `+77011234567`.
4. **Deploy** батырмасын басыңыз. Бірнеше минуттан кейін `https://bari-xxxx.onrender.com` сияқты сілтеме шығады.

Дерекқор сақталатын диск ақылы жоспарда ғана бар (Starter, айына шамамен 7$). Тегін жоспарда сервер қайта іске қосылған сайын деректер өшеді, сондықтан ол тек көрсетуге жарайды.

### Қазақстандағы сервер (нақты іске қосу үшін)

Қазақстан заңы бойынша азаматтардың дербес деректері Қазақстан аумағындағы серверде сақталуы тиіс. Нақты іске қосу үшін қазақстандық VPS қолданыңыз (мысалы PS.kz, Hoster.kz):

```bash
# Ubuntu серверінде
docker build -t bari .
docker run -d --restart=always -p 80:3000 -v bari-data:/data \
  -e ADMIN_PHONES=+77011234567 -e OTP_SECRET=$(openssl rand -hex 32) bari
```

Алдына HTTPS қосыңыз (мысалы Caddy немесе nginx + Let's Encrypt). Геолокация мен PWA тек HTTPS арқылы жұмыс істейді.

## Баптаулар (`server/.env`)

| Атауы | Мағынасы | Әдепкі |
|---|---|---|
| `PORT` | Сервер порты | `3000` |
| `DB_PATH` | SQLite дерекқор файлы | `./data/bari.db` |
| `SMS_MODE` | `demo`: код экранда шығады (тек тест үшін!) | `demo` |
| `ADMIN_PHONES` | Әкімші нөмірлері, үтір арқылы | — |
| `OTP_SECRET` | Кодтарды шифрлайтын құпия сөз. Нақты серверде міндетті түрде өзгертіңіз | — |
| `SEED_DEMO` | Бос дерекқорға 10 демо мекеме қосу | `1` |
| `SIMULATE` | Pro қосымшасындағы тест жүргізу режимі | `1` |

## Нақты іске қосар алдында не істеу керек

Платформа жұмыс істейді, бірақ шын клиенттер мен ақша үшін мыналар керек:

1. **SMS провайдері.** Қазақстандық SMS сервисімен келісім жасап, `server/lib/sms.js` файлына қосу, содан кейін `SMS_MODE=provider` қою. `demo` режимімен шын адамдарға ашуға болмайды.
2. **Картамен төлеу.** Банк эквайрингімен келісім керек. Әзірге тек қолма-қол төлем бар.
3. **Карта және маршрут.** Қазір OpenStreetMap-тың тегін серверлері және шамамен есептелген қашықтық қолданылады. Нақты жұмыс үшін 2GIS немесе басқа ақылы карта мен маршрут API керек.
4. **Заң жағы.** ЖШС немесе ЖК тіркеу, такси мен жеткізу қызметіне қойылатын талаптар, пайдаланушы келісімі, дербес деректерді сақтау. Заңгермен кеңесіңіз.
5. **Жүргізушілерді тексеру.** Куәлік, техпаспорт, сақтандыру. Әзірге әкімші қолмен растайды.
6. **Қолдау қызметі.** Клиент пен жүргізушіге шағым беру мүмкіндігі.
7. **Өсу.** Пайдаланушы көбейгенде SQLite орнына PostgreSQL, кейін App Store мен Google Play-ге арналған мобильді қосымшалар.
