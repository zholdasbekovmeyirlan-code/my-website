6 NOWPayments кілттері

  • Settings → Payments → API keys → Add new key → кілтті көшіріңіз.
  • Settings → Payments → Instant payment notifications → IPN secret key жасап, көшіріңіз.
  • Set balance / Payout wallet: ақша түсетін әмиян (мысалы Bybit USDT TRC20 мекенжайы).
  • Supabase → Edge Functions → Secrets:
    NOWPAYMENTS_API_KEY = API key
    NOWPAYMENTS_IPN_SECRET = IPN secret key

⚠️ Кілттерді ешкімге жібермеңіз, тек Supabase-ке қойыңыз.
